# The documentation site

The public documentation site for RAPID now has a repository and a
build: Markdown sources, Sphinx with MyST and ABlog, hosted on Read the
Docs once the project is connected. Every page exposes its source, the
site root serves `llms.txt`, the site build fails on warnings, and the
repository's checks also fail on a broken link.

What it holds today: the design documents in System, how the project is
run in Project, and this log.

Next: the Read the Docs project, then Products and Science pages as the
pipeline documentation is re-derived here page by page.
