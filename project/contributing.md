# Contributing

RAPID is developed in the open. The pipeline's contribution guidelines
and code of conduct live with the code, in the pipeline repository:

- [Contributing to the pipeline](https://github.com/Caltech-IPAC/rapid/blob/main/CONTRIBUTING.md)
- [Code of conduct](https://github.com/Caltech-IPAC/rapid/blob/main/CODE_OF_CONDUCT.md)

The code of conduct applies to this site and its repository as well.

## This site

The site is built from the Markdown sources in
[Caltech-IPAC/rapid_docs](https://github.com/Caltech-IPAC/rapid_docs).
Open a pull request; the checks that must pass before a change merges
are the ones the repository's README lists for a local build: the
public-safety scan, the warnings-as-errors build, the link check, and
the acceptance script. Every pull request gets a preview build.

Reference pages are updated in place; posts are never revised after
publication. A correction to something a post said goes into the
reference page it concerns.
